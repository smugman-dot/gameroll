# <img src="https://raw.githubusercontent.com/smugman-dot/gameroll/refs/heads/main/src/app/favicon.ico" width="28" height="28" />  Gameroll

A new modern way to doomscroll your games!

Gameroll is a game discovery app built around swipeable cards. Instead of digging through endless lists and store pages, you flick through games one at a time and maybe find your next favorite game.

🔗 **Live demo:** https://gameroll.vercel.app

![Gameroll screenshot](https://github.com/user-attachments/assets/10b2c729-d7b8-431f-a42f-c42aa21049f2)

## Features
- Tinder-style swipeable game cards
- Pick your favorite genres to customize your feed.
- Swipe right to like a game, left to skip
- Recommendations that adapt to your swipes
- No personal info stored
- More coming soon (WIP)

## Tech stack

- [Next.js](https://nextjs.org/) (App Router)
- [Supabase](https://supabase.com/) for game data and embeddings
- [IGDB](https://api-docs.igdb.com/) for game data
- [SteamGridDB](https://www.steamgriddb.com/) for fallback images
- Deployed on [Vercel](https://vercel.com/)

## Running locally
```bash
git clone https://github.com/smugman-dot/gameroll
cd gameroll
npm install
npm run dev
```
